# Historical intake review fixtures

These snapshots preserve regression coverage for stale difficulty audits, gender
repair lineage, and idempotent reviewed corrections. They are not approvals of
the current maps. Model decisions and source/map digests are unchanged. Absolute
machine paths in gender requests are replaced with repository-relative paths;
reviewer attribution in corrections is retained because it participates in the
pinned maps' approval identity and idempotence checks. Authoring checkpoints,
review exports, and internal discussion are intentionally not distributed.
